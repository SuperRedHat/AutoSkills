# 验收包：一页看完等你验收的任务

## 怎么敲

```
node <套件目录>/scripts/autoskills.mjs accept <项目目录>
```

读项目的账本，把等你验收的任务排成一页 HTML，写到 `<项目>/.autoskills/acceptance/<时间戳>.html`，把路径打印出来，用浏览器打开即可。不起会话，不花 token，不写账本。

选项：`--out <文件>` 改写到别处（不能写进项目的账本目录 `.claude/state/`，那样会用页面盖掉账本文件，命令会拒绝）；`--help` 看用法。没有账本退出 1，用法错误退出 2。

## 页面怎么读

- 页首：项目名、生成时间、等你验收的个数，下面是一句可以直接回的例子。
- 任务按模块分组。门禁任务排最前，其次是“通过后能放开更多任务”的，再按账本先后。先看最上面的。
- 每个任务一块：
  - **驱动复验**：长跑驱动在提交后自己重跑了验证命令。四种写法：
    - “通过”：可以放心一些。
    - “没过，建议驳回”：下面写原因。有命令没过，就列出命令、退出码（超时或没能启动会照实写）和日志位置；工作目录不干净，就列出没提交的文件，这时验证命令没有跑。
    - “没有跑，任务没有验证命令”：这个任务本来就没有可跑的命令，不算没过，照验收标准和检查清单自己看。
    - “没有复验记录”：这个任务不是长跑驱动做的，没人替你跑过。
  - **验收标准**、**检查清单**：照着逐条看。
  - **备注原文**：里面有提交号、证据位置和实现者做的假设。
  - **通过后能放开的任务**：你点头后哪些任务就能开工。
- 没有等你验收的任务时，页面照样生成，写明“没有等你验收的任务”。

## 看完怎么回

在会话里回一句，必须点名任务：

- `T3.5、T3.8 通过`
- `T3.6 驳回：<原因>`

不点名的“都通过”，验收技能不认。

## 有长跑在跑时为什么先停

长跑里的会话和验收处理都会写账本，两边同时写会丢更新。页首出现“有长跑正在跑”的提示时，先停下长跑，再回验收。提示里给出了可以直接粘贴的停止命令，形式是：

```
node <套件目录>/scripts/autoskills.mjs stop <项目目录>
```

它让驱动做完手上的任务后结束。

# AutoSkills

> 占位文档。正式内容将由 TASK-069 重写。

本仓库承载 CouncilFlow 的配套工作流：

- `skills/project-*` — 三端共享的 `project-*` 工作流 skills 源
- `mcp/project-manager/` — `project-manager` MCP server（Node 工程）源
- `templates/` — 全局 / repo-local CLAUDE.md 模板
- `scripts/bootstrap.{ps1,sh}` — 一键部署脚本
- `mcp-manifest.json` — MCP 注册 manifest

与 [CouncilFlow](https://github.com/SuperRedHat/CouncilFlow) 配套使用。
